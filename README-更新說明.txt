Shopee 編輯器：下載修正包（2026-10-30）

【如何更新】
1. 關閉正在使用的編輯器分頁。
2. 將本 ZIP 的 index.html、js 資料夾，放進「原本 Shopee 工具的 index.html 所在資料夾」，依相同路徑覆蓋／合併。
3. 新增的 js/vendor 資料夾必須一起放入，包含兩支 min.js。授權文件請保留。
4. 保留原本的 html、fonts、圖片與其他 JS。這是異動檔更新包，不是完整工具。
5. 重新開啟工具並按 Ctrl＋F5，再試原本無法下載的作品。

程式異動／新增共 5 個：
index.html
js/bn-editor-plugin.js
js/layout-runtime.js
js/vendor/html2canvas.min.js
js/vendor/jszip.min.js
另附引擎授權文件與本說明。

【已確認的直接原因】
背景改成以中心縮放、位移後，CSS 位置會使用 calc(...)。
原本 html2canvas 1.4.1 的背景位置解析無法處理這個值，會回傳失敗；外層原本只顯示「截圖逾時或回傳空白」。
已在 HBN 測試畫布重現相同失敗。新版只在截圖副本將背景位置與大小轉成精確的 px 數值，保留正式畫布原本的中心縮放與位移參數。

【一併修正】
• 下載前等待商品、LOGO、人物、背景圖片及字型；載入與解碼都有期限。
• 原本外層 12 秒的截圖期限，短於引擎預設圖片等待 15 秒。新版整合期限與取消／還原，顯示明確失敗原因。
• 截圖結束一律還原暫時樣式、控制點、提示與下載按鈕，可直接重試。
• 修正結束後又送出「處理中」通知，使 BODA 外層轉圈視窗重新打開的問題。
• 圖片未超過 KB 時，只截一次並保留 PNG；確定需壓縮才另外整理背景與前景。
• 分層截圖失敗時保留已完成的主圖，不會留下背景隱藏或透明的編輯畫面。
• 單張 PNG、SearchICON 84×84、多版位 ZIP 與暫存 JSON 流程保留。
• 在截圖副本還原原始畫布尺寸，避免預覽縮放影響輸出尺寸或位置。
• 連續旋轉使用獨立資料計算，舊工作較晚完成不會覆蓋最新圖片；旋轉尚未完成時不輸出中間狀態。
• 截圖與 ZIP 引擎改用內附檔案，避免 CDN 連線問題。載入失敗可重試。
• 背景或其他來源不允許匯出時會給出明確提示，請改用本機圖片上傳。
