什麼是 MCP？

Model Context Protocol (MCP) 是一個開放協議，用於連接 AI 助手與外部資料、工具和系統。通過 MCP，Claude 可以：

  • 訪問實時資料和系統狀態
  • 執行特定的操作和命令
  • 查詢知識庫和資源
  • 與外部 API 進行交互
  • 獲取上下文相關的資訊

安裝配置

步驟 1：獲取 MCP 連結

Shopee MCP 服務地址：

https://twtc.shopee.tw/mcp

步驟 2：在 Claude Code 中配置

編輯 .claude/mcp.json 文件：

{
  "mcpServers": {
    "shopee-tech": {
      "url": "https://twtc.shopee.tw/mcp"
    }
  }
}

💡 提示

如果文件不存在，可以新建一個。配置後 Claude Code 會自動載入這個 MCP。

步驟 3：驗證連接

使用測試工具驗證 MCP 連線狀態：

GET https://twtc.shopee.tw/mcp/health

基本使用

三種主要操作

1. 健康檢查

驗證服務是否運行正常

GET /health
回應: { status: "healthy", version: "1.0.0" }
2. 執行工具

調用 MCP 提供的工具進行特定操作

POST /tools/{tool_name}
請求體: { "param": "value" }
回應: { "result": "..." }
3. 查詢資源

檢索知識庫、配置或其他資訊

GET /resources?type=config
回應: { "resources": [...] }

使用示例

示例 1：獲取系統配置

// 請求
{
  "method": "GET",
  "url": "https://twtc.shopee.tw/mcp/resources?type=config",
  "headers": {
    "Accept": "application/json"
  }
}

// 回應
{
  "resources": [
    {
      "id": "config:tech-stack",
      "name": "Tech Stack Configuration",
      "type": "config"
    }
  ]
}

示例 2：執行服務檢查

// 請求
{
  "method": "POST",
  "url": "https://twtc.shopee.tw/mcp/tools/check-service",
  "body": {
    "service": "api-gateway",
    "region": "sg"
  }
}

// 回應
{
  "service": "api-gateway",
  "status": "healthy",
  "latency": "45ms",
  "uptime": "99.98%"
}

示例 3：查詢監控指標

// 請求
{
  "method": "POST",
  "url": "https://twtc.shopee.tw/mcp/tools/get-metrics",
  "body": {
    "service": "order-service",
    "timeframe": "1h",
    "metrics": ["cpu", "memory", "requests"]
  }
}

// 回應
{
  "cpu_usage": 34.5,
  "memory_usage": 62.1,
  "requests_per_second": 1234
}

可用工具

工具名 說明 請求方法
health-check 檢查 MCP 服務健康狀態 GET
list-services 列出所有可用的服務 GET
check-service 檢查特定服務狀態 POST
get-metrics 獲取服務監控指標 POST
query-logs 查詢服務日誌 POST
get-config 獲取服務配置 GET

資源查詢

支援的資源類型

配置資源 
GET /resources?type=config
type: "config" | 檢索系統配置和環境變數
文檔資源 
GET /resources?type=docs
type: "docs" | 檢索 API 文檔和技術規範
指標資源 
GET /resources?type=metrics
type: "metrics" | 檢索服務監控指標

搜索資源

GET /resources/search?q=order&type=docs

回應:
{
  "results": [
    {
      "id": "docs:order-api",
      "title": "Order Service API",
      "description": "API 文檔",
      "type": "docs"
    }
  ]
}

常見問題

❌ 連線超時

問題：連線到 MCP 伺服器超時

解決：
  • 檢查網路連接是否正常
  • 確認 MCP 伺服器 URL 是否正確
  • 檢查防火牆設置
  • 使用 curl https://twtc.shopee.tw/mcp/health 測試

❌ 401 未授權

問題：收到 401 Unauthorized 錯誤

解決：
  • 確認是否已通過身份驗證
  • 檢查 API 令牌是否有效
  • 查看 MCP 文檔中的身份驗證要求

❌ 404 找不到工具

問題：工具返回 404 Not Found

解決：
  • 使用 GET /tools 列出所有可用工具
  • 檢查工具名稱是否拼寫正確
  • 確認工具版本是否相容

❌ 請求參數錯誤

問題：收到 400 Bad Request

解決：
  • 驗證請求體是否為有效的 JSON
  • 檢查是否提供了所有必需的參數
  • 查看工具的文檔以了解參數要求

最佳實踐

  • 總是先進行健康檢查，確認服務可用
  • 使用適當的超時時間（推薦 30 秒）
  • 實施重試機制處理暫時性失敗
  • 記錄所有 API 呼叫便於調試
  • 定期驗證 MCP 連線狀態
  • 使用請求 ID 追蹤和關聯日誌
